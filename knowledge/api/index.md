# API

- [Html](./html.md) - Root builder; entry point for constructing a document
- [Div](./div.md) - Builder for a `<div>` element and its children
- [Attributes](./attributes.md) - Trait shared by element builders for setting attributes
- [Element](./element.md) - Internal machinery shared by all element builders (crate-private)
- [HtmlWriter](./writer.md) - Internal string writer that tracks indentation (crate-private)
